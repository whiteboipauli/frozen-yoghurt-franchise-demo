# Frozen Yoghurt Franchise – Warenwirtschaft & Filialsteuerung (Demo)

Demo-Prototyp für Vorführungen. **Alle Daten sind fiktiv** (Läden, Personen, Umsätze, Rechnungen). Es gibt keinen Server und keine echte Anbindung.

**Live-Demo:** https://whiteboipauli.github.io/frozen-yoghurt-franchise-demo/

## Lokal starten

```
npm install
npm run dev
```

## Hinweis zu den Daten

Alle Änderungen (Bestellungen, Zählungen, Dienstplan …) werden nur im Browser des jeweiligen Besuchers gespeichert (localStorage). Wer die Seite neu lädt oder einen anderen Browser nutzt, startet wieder mit den Demodaten.
